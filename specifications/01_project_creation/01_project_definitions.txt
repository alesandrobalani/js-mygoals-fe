Este projeto será o front end para um sistema de controle financeiro familiar.
Ele deve ser criado usando react.
Ele deve conter o README e o gitignore para atender a esta tecnologia.
Ele consumirá recursos do projeto js-mygoas-be que esta contido na pasta C:\dev\js-mygoals-be\.
Este projeto visa atender um front end para ser utilizado no desktop Web, e também no Mobile Android.
Construa um designe de cores clean.
Neste momento deve ser criada a funcionalidade de autenticação de usuário, e as telas de gestão de usuários.
Crie a estrutura contempando os testes automatizados.
Os menus da aplicação devem ser apresentados conforme a role do usuário autenticado, o usuário admin terá permissão apenas para acessar os recursos de de administração de usuários, já os que não administradores terão acesso ao dashboard de transações.
